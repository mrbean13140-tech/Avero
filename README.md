# Avero

Установка и удаление приложений (.ipa) на iPhone/iPad с Windows через браузер — как раздел «Приложения» в iMazing.

## Скачать
**[Avero.exe — последняя версия](../../releases/latest)** — установка не нужна, Python не нужен.

## Как пользоваться
1. Один раз поставьте **[Apple Devices](https://apps.microsoft.com/detail/9NP83LWLPZ9K)** из Microsoft Store (или iTunes) — это USB-драйвер Apple, без него Windows не видит iPhone.
2. Подключите iPhone кабелем, разблокируйте, нажмите «Доверять этому компьютеру».
3. Запустите `Avero.exe` — откроется браузер. Перетащите .ipa в окно.

С телефона в той же сети: адрес `http://<IP ПК>:8765` показан в окне программы.

## Возможности
- список подключённых устройств (модель, iOS)
- установка одного или нескольких IPA с прогрессом
- список пользовательских приложений, поиск, удаление

## Ограничения
- IPA должен быть подписан для этого устройства (ad-hoc/dev-профиль с его UDID, enterprise или переподписан). Иначе iOS вернёт ошибку подписи.
- Авторизации нет — не открывайте порт 8765 в интернет.

## Сборка
Каждый push в `main` собирает exe в GitHub Actions и публикует релиз.
